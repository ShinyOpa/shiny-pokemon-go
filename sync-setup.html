Synchronisatie eenmalig instellen

Begin op het apparaat met je volledige verzameling. De synchronisatiefunctie staat klaar, maar werkt pas als de online database hieronder is ingesteld.

  1. Open Supabase, meld je aan en maak een project aan. Kies een abonnement dat bij je past en bewaar het databasewachtwoord zelf.
  2. Open in dat project de SQL Editor. Kopieer onderstaande database-instelling, plak die in een nieuwe query en druk op Run.

    Download SQL

  3. Zoek in het project de Project URL en de Publishable API key (de oudere anon key werkt ook). Gebruik geen secret key of service_role key.
  4. Ga terug naar Pokédex GO. Open 🔄 Synchroniseren tussen apparaten → Eerste apparaat instellen. Vul URL en publishable key in. Druk op Nieuwe synchronisatie starten. Je bestaande aantallen worden online opgeslagen.
  5. Druk op Kopieer koppelcode. Open dezelfde Pokédex GO op je andere apparaat, plak de code onder Ander apparaat koppelen en druk op Dit apparaat koppelen. Dat apparaat neemt de online aantallen over; de lokale aantallen worden eerst als herstelkopie bewaard.

Na koppelen worden wijzigingen tijdens gebruik automatisch bijgewerkt. Zonder internet blijft de verzameling lokaal bruikbaar. Een conflict op dezelfde Pokémon wordt beslist door de laatst gesynchroniseerde wijziging; wijzigingen aan verschillende Pokémon blijven behouden.

Bewaar de koppelcode privé: iemand met die code kan je online verzameling bekijken en aanpassen. Koppeling verbreken zet synchronisatie op dat apparaat uit, maar trekt eerder gedeelde codes niet in. Een nieuwe synchronisatie maken geeft een nieuwe code. Verwijder een oude verzameling desgewenst vanuit je eigen Supabase-database.
